# Move Light

Move Light turns one move date into a paced, practical checklist. It helps people start early enough for the important stuff—then keeps the final two days from becoming chaos.

## What it handles

- A countdown that reveals the right tasks as moving day approaches
- Different plans for a small move, family home, or long-distance move
- Packing, utilities, address changes, and final-handoff prompts
- Personal tasks for the details only you know about
- Check-off progress and a copyable plain-text plan

## Private by default

There is no account. Your move date, completed tasks, and personal tasks stay in browser storage on your device.

## Checks

node --test tests/move-light.test.mjs
